護照 護照要放隨身包,不要放託運行李

  • 護照效期要超過離開申根區日期(11/12)後至少 3 個月,也就是到 2027/2/12 以後都要有效。
  • 第一次入境(蘇黎世)會被登記指紋與臉部照片,請預留排隊時間。
  • 建議另存一份護照影本和照片在手機與雲端,並在行李內放紙本影本。

插座與電器

瑞士用 Type J、Type C,德國用 Type C / E。

  • 有些 C 型插頭的腳比較粗,插不進瑞士的 J 型插座。
  • 筆電、吹風機這類需要接地的電器,在瑞士要準備支援 Type J 的轉接頭。

德國自動售票機刷卡

  • 信用卡付費會要求輸入 4 位數 PIN。台灣信用卡一般沒有,出發前請銀行提供「預借現金」PIN。
  • 已在國外來不及申請:先按 # 跳過,或輸入 0000 讓機器辨識為國外卡。
  • 仍然不行就到櫃台購票,告知要用簽單簽名。

山區日小提醒

  • 出發前一晚和當天早上看山上即時攝影機,雲太厚就換行程順序。

  • 高山日照強,墨鏡和防曬乳要帶。
  • 11 月是設施維修期,先到各山的官網查營運。
