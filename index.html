出發前必看 BEFORE YOU GO

護照 護照要放隨身包,不要放託運行李

  • 護照效期要超過離開申根區日期(11/12)後至少 3 個月,也就是到 2027/2/12 以後都要有效。
  • 第一次入境(蘇黎世)會被登記指紋與臉部照片,請預留排隊時間。
  • 建議另存一份護照影本和照片在手機與雲端,並在行李內放紙本影本。
  • ETIAS 目前尚未生效,也沒有確定啟用日期,11 月出發不需要申請。出發前一週再到官方網站確認一次。

時差 11 月瑞士、德國慢台灣 7 小時

歐洲夏令時間在 10/25 結束,11 月比台灣慢 7 小時。手機設定自動時區即可,訂票和集合時間一律看當地時間。

Interrail 通行證與座位預約

  • 出發前先在 App 設定好旅行日期,第一次搭車前要啟用。
  • 11/8 蘇黎世 09:32 → 慕尼黑 13:16 要先買座位票,並把訂位車票印出來。
  • 11/10 新天鵝堡一日遊和山上行程是另外購買的票,不含在通行證內。

插座與電器

瑞士用 Type J、Type C,德國用 Type C / E。

  • 有些 C 型插頭的腳比較粗,插不進瑞士的 J 型插座。
  • 筆電、吹風機這類需要接地的電器,在瑞士要準備支援 Type J 的轉接頭。

德國自動售票機刷卡

  • 信用卡付費會要求輸入 4 位數 PIN。台灣信用卡一般沒有,出發前請銀行提供「預借現金」PIN。
  • 已在國外來不及申請:先按 # 跳過,或輸入 0000 讓機器辨識為國外卡。
  • 仍然不行就到櫃台購票,告知要用簽單簽名。
